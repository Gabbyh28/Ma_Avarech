# מה אברך?

אפליקציית ווב (PWA) שעונה על השאלה "מה מברכים על זה?" – ברכה ראשונה וברכה אחרונה לכל מאכל.

## מה יש באפליקציה

- **חיפוש** – מאגר של כ־100 מאכלים, עם חיפוש לפי שם או שם נרדף (למשל "חלה" ← לחם) וסינון לפי קטגוריה.
  לחיצה על מאכל מציגה את נוסח הברכה הראשונה והאחרונה, ומחלוקות או מנהגים שונים אם יש.
- **הצלחת שלי** – מוסיפים כמה מאכלים ומקבלים:
  - את סדר הקדימה בברכות הראשונות (מזונות ← הגפן ← העץ ← האדמה ← שהכל);
  - ברכה אחרונה משולבת, למשל "על המחיה ועל הגפן ועל העץ", עם הנוסח המלא;
  - טיפול בלחם (המוציא פוטר הכל, ברכת המזון בסוף) ובפטור של פירות העץ על ידי "על העץ".
- **מידע** – סדר הברכות, שיעורים (כזית, רביעית) והערות.
- עובד **בלי אינטרנט** ואפשר להתקין אותו למסך הבית בטלפון.

## הרצה

אין צורך בבנייה. מגישים את התיקייה בכל שרת סטטי:

```bash
npm start        # http://localhost:8080
npm test         # בדיקות לוגיקה
```

אפשר לפרסם ב־GitHub Pages: Settings ← Pages ← Deploy from branch.

## מבנה

| קובץ | תפקיד |
