# מה אברך?

אפליקציית ווב (PWA) שעונה על השאלה "מה מברכים על זה?".

**באוויר:** https://gabbyh28.github.io/Ma_Avarech/

## מה יש באפליקציה

- **חיפוש** – כ־190 מאכלים עם איור לכל אחד, חיפוש לפי שם או שם נרדף וסינון לפי קטגוריה. לחיצה על מאכל מציגה את נוסח הברכה הראשונה והאחרונה, והערות על מחלוקות.
- **הצלחת שלי** – מוסיפים כמה מאכלים ומקבלים איור של הצלחת, את סדר הקדימה בברכות הראשונות, וברכה אחרונה משולבת (למשל "על המחיה ועל הגפן ועל העץ"). אפשר לשתף את סדר הברכות בוואטסאפ.
- **ברכות נוספות** – ברכות הריח, ברכות הראייה ושהחיינו.
- **הלכות והגדרות** – נוסח (אשכנז / ספרד / עדות המזרח), פירות ארץ ישראל, ניקוד, מחשבון "אכלתי כשיעור?", סדר הקדימה ושיעורים.
- **מסך קריאה** – כל ברכה במסך מלא באותיות גדולות.
- עובד בלי אינטרנט, וניתן להתקנה למסך הבית.

## פיתוח

אין צורך בבנייה. מגישים את התיקייה בכל שרת סטטי:

```bash
npm start                     # http://localhost:8080
npm test                      # בדיקות לוגיקה
npm run build                 # קובץ HTML יחיד ב-dist/
node scripts/make-assets.mjs  # אייקונים ותמונת שיתוף (דורש Playwright)
node scripts/make-review.mjs  # טבלת בדיקה הלכתית ב-docs/
```

כל דחיפה לענף `main` מריצה את הבדיקות ומפרסמת ל-GitHub Pages (`.github/workflows/pages.yml`).

## מבנה

| קובץ | תפקיד |
|---|---|
| `src/foods.js` | מאגר המאכלים – כאן מוסיפים מאכלים, כולל פסיקה שונה לעדות המזרח (`edot`) |
| `src/brachot.js` | נוסחי הברכות (מנוקדים), סדר קדימה וחישוב הצלחת |
| `src/extras.js` | ברכות הריח, הראייה ושהחיינו |
| `src/illustrations.js` | איורי המאכלים ואיור הצלחת |
| `src/app.js` | הממשק |
| `docs/halacha-review.csv` | טבלה לבדיקת רב |
